# ナンバープレート認識による来場者分析システム

車のナンバープレートの画像から、地名・分類番号・ひらがな・一連指定番号を認識し、結果をデータベースに記録して、来場者がどの地域から来たかを集計・表示するシステムです。

<img src="./samples/gui.png" alt="アプリのメイン画面" width="600">


## 処理の流れ

```
画像の入力 ──► 前処理 ──► 要素への分割 ──► 文字認識 ──► 結果の表示・DB への保存 ──► 地域分布のグラフ
```

### 1. 前処理：認識しやすい画像にする

光によってコントラストが下がったり、影がついたりすると、認識精度が落ちます。そこで、次の2つの処理で画像を改善しています。

- **適応的ヒストグラム平坦化**でコントラストを上げる。下の図の上段が通常の画像を二値化したもの、下段がコントラストを改善してから二値化したものです。下段では地名が消えずに残っています。

  <img src="./samples/contrast.png" alt="コントラスト改善の効果" width="500">

- **適応的二値化**で、影の影響を受けずに二値化。下の図の中央が通常の二値化、右が適応的二値化です。

  <img src="./samples/tekioutekinitika.png" alt="適応的二値化の効果" width="600">

### 2. 分割：プレートを要素ごとに切り取る

ヒストグラムで上下・左右の区切りを見つけ、ハフ変換で数字を1桁ずつ切り分けます。

<img src="./samples/hist.png" alt="ヒストグラムによる分割" width="300">
<img src="./samples/hahu.png" alt="ハフ変換による分割" width="200">

分割の流れ：

<img src="./samples/split.png" alt="ナンバープレートを要素に分割する流れ" width="500">

### 3. 文字認識：地名・ひらがな・数字を認識する

EfficientNet をファインチューニングして、地名・ひらがな・数字の認識器をそれぞれ作りました。開発期間の都合で、地名は中国地方（広島、福山、鳥取、島根、岡山、倉敷、山口、下関、出雲）に限定しています。

テスト画像35枚での認識精度は下のグラフのとおりです。誤認識の多くは、プレートの汚れや影によるものでした。

<img src="./samples/seido.png" alt="認識精度のグラフ" width="400">

### 4. データベースと集計

認識した各要素と撮影日時を MySQL に保存します。車の入退場の管理を想定しているため、撮影時刻なども記録します。保存したデータから、日間・月間・年間の地域分布をグラフで表示できます。

<img src="./samples/database.png" alt="データベースに保存した認識結果" width="500">

## リポジトリ構成

```
VisitorAnalysisSystem/
├── main.py           # アプリ本体（tkinter の GUI）
├── recognition/      # 認識処理の全体（NPrecognition_v3.py）
├── MyLibrary/        # 前処理、分割、各要素の認識、DB 操作
├── myModels/         # 学習済みモデル
├── training/         # 認識モデルの学習スクリプト
├── test_data/        # 評価用画像
├── experiments/      # 認識精度・処理時間の評価スクリプト
├── tools/            # データセット作成などの補助スクリプト
├── DB/               # データベースの作成手順
├── samples/          # README 用の画像
├── outputs/          # 評価結果のログ、モデル構造の図
└── archive/          # 開発中に使った古いスクリプト
```


## 動作環境

- Windows 11
- Python 3.11
- MySQL 8.1（地域分布の集計を使う場合のみ）

## インストール

```bash
git clone https://github.com/Tsubaki26/VisitorAnalysisSystem.git
cd VisitorAnalysisSystem
pip install -r requirements.txt
```

## 使い方


```bash
python main.py
```

1. 画面左上の「画像ファイルを選択」ボタンで、ナンバープレートの画像を選びます。選ぶと自動で認識が始まります。
2. 左上に入力画像、左中央に画像の情報（サイズ、撮影日）、左下にログ（処理時間やエラー）、右上に認識結果が表示されます。分割した画像は `images/output_images/` に保存されます。
3. 「来場者の分布を表示」ボタンを押すと、グラフのウィンドウが開きます（データベースが必要です）。
   - 年間・月間・日間から期間を選べます。
   - チェックボックスで、鳥取県をグラフに含めるかどうかを切り替えられます。
   - ウィンドウ下部の「進む」「戻る」ボタンで、日付を移動できます。
